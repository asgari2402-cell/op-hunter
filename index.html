Klick auf ein Produkt: Details, Release und Händler-Suche
Die Eingabe filtert sofort. Mit Enter oder „Suchen / prüfen“ wird auch ein nicht katalogisiertes Produkt über alle 50 Shops geprüft.
Die Produktprüfung durchsucht die 50 Shops aus deiner Excel-Datei. Angezeigt werden ausschließlich erkannte Angebote mit positivem Lager- oder Vorbestellstatus. Die Lagerdaten werden automatisch durch GitHub Actions aktualisiert. Auf diesem Gerät ist keine Installation erforderlich.

Einstellungen

Priorität: Neue Produkte → Vorbestellungen → Restocks → Preisänderungen

Geplante Uhrzeit: täglich 06:00 Uhr (Europe/Berlin)

Die Einstellung wird lokal in diesem Browser gespeichert.

Wichtig: Diese einzelne HTML-Datei kann Shops wegen Browser-Sicherheitsregeln nicht selbstständig im Hintergrund durchsuchen. Für echte tägliche Scans um 06:00 Uhr braucht sie zusätzlich einen laufenden Server, Cronjob oder Automationsdienst. GitHub Actions prüft die Händler nach Zeitplan. Shops mit Captcha, Login oder Bot-Schutz können einzelne Prüfungen blockieren.
